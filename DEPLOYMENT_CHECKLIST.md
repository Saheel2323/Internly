# Internly — quick start checklist

- [ ] Upload all files from this folder to a public GitHub repository.
- [ ] Enable GitHub Pages from `main` / root.
- [ ] Open the published HTTPS link on your Android phone in Chrome.
- [ ] Choose Install app / Add to Home screen.
- [ ] Open Internly and add internship details.
- [ ] Export a JSON backup once you have entered data.
- [ ] If you want AI reports, create a Gemini API key and add it in Internship details.

**Cost note:** This PWA package has no paid hosting dependency. Gemini API free-tier usage is subject to Google's current eligibility, quotas and terms. Google Play Store publishing is not included.
